Looks like Notepad

Mica-dark chrome, title-bar tabs, File / Edit / View, and a status bar for line, zoom, and encoding.

Live Markdown

Format as you type, or switch to Markdown source. Bold, italic, headings, lists, and links.

Local files

Open and save txt or md, keep recent files, and restore unsaved tabs from the last session.

Tasks

A simple task list lives next to Settings. Checked items move down with the same dark UI.
